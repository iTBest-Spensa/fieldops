FIELDOPS DISPATCH V8.6 — HOVER ONLY + TRUE SOLID TOOLTIP

Fixes:
- Removed click behavior from Daily Track activities and gaps.
- Track segments are no longer buttons.
- Hint appears only while the mouse is passing over an activity/gap.

Transparency fix:
- Hint is now rendered outside the track/table using a React portal.

- Day mode popup uses solid WHITE.
- Night mode popup uses solid SLATE-950.
- z-index 99999.
- No opacity/transparency is used.
- Pointer arrow remains.

Status colors remain:
Complete = Green
Travelling = Blue
On Site = Blue
Working = Orange
Break/Lunch = Gray
Assigned = Purple
Available = Gray
