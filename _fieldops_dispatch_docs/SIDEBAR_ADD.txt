FIELDOPS SIDEBAR ADDITION
=========================

Add a Dispatch navigation item under Operations, between Operations and Work Orders.

If your sidebar navigation uses lucide-react icons, add RadioTower to the lucide-react import and add this item:

{ name: "Dispatch", href: "/dispatch", icon: RadioTower },

Recommended order:

Dashboard
Operations
Dispatch
Work Orders
Customers

Do not replace your current sidebar blindly. Your current FieldOps sidebar already has the correct Songa-derived day/night styling, so only add the new item.
